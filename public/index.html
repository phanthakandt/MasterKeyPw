เข้าสู่ระบบเป็น · ซิงก์ทุกอุปกรณ์ที่เข้าด้วยบัญชีนี้

เข้าสู่ระบบเพื่อซิงก์

บัญชี Google ใช้เพื่อดึงตู้ที่เข้ารหัสแล้วของคุณจากคลาวด์เท่านั้น Master Key เป็นคนละส่วนกันและไม่ถูกส่งออกจากเบราว์เซอร์นี้ คลาวด์ไม่สามารถเปิดดูรายการของคุณได้

บัญชีนี้ถูกระงับ

บัญชีนี้ใช้งานตู้บนเว็บนี้ไม่ได้ หากคิดว่าเป็นความผิดพลาด ให้ติดต่อผู้ดูแลเว็บ

ปลดล็อกตู้บนเครื่องนี้

ถ้าลืม Master Key จะกู้ข้อมูลคืนไม่ได้เลย ไม่มีปุ่มรีเซ็ต ควรจด Key ไว้ในที่ปลอดภัย

ข้อมูลบนคลาวด์เข้ารหัสต่างจากเครื่องนี้

อาจมีอุปกรณ์อื่นเปิดเว็บรุ่นเก่าค้างไว้ หรือกู้คืนข้อมูลสำรอง เครื่องนี้จึงหยุดซิงก์ไว้ก่อนเพื่อไม่ให้เขียนทับกัน ลองรวมข้อมูลด้วย Master Key ก่อน

เพิ่มรายการ

ถ้าลืม Key ของรายการ จะดูรหัสผ่านนี้ไม่ได้อีก แต่ยังลบรายการด้วย Master Key ได้

สำรองข้อมูล / ย้ายเครื่อง

ตู้ซิงก์ข้ามอุปกรณ์ผ่านคลาวด์แบบเข้ารหัสแล้ว แต่ควรเก็บข้อความสำรองไว้ด้วยเผื่อบัญชีมีปัญหา คัดลอกข้อความด้านล่าง (ยังเข้ารหัสอยู่) ไปเก็บไว้ แล้ววางกลับเมื่อต้องการกู้คืน ต้องใช้ Key เดิมเปิด การกู้คืนจะแทนที่ข้อมูลบนคลาวด์ด้วย

แต่ละรายการมี Key ของตัวเอง ดูหรือแก้ไขรหัสผ่านต้องใส่ Key ของรายการนั้นทุกครั้ง รหัสที่แสดงจะซ่อนเองใน 5 วินาที รายการเก่าที่ยังไม่ได้ตั้ง Key แยกใช้ Master Key

เครื่องนี้จำตู้ไว้เพื่อแสดงรายการโดยไม่ต้องใส่ Key กด “ออกจากระบบ” เพื่อให้เครื่องลืม
